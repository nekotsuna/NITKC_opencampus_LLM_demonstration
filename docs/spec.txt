# 概要
LLM体験会用のアプリケーション。モデルによる推論は別のPCで行い、本PC(クライアントPC)はwebアプリケーションを立ち上げて、ユーザーの操作によってモデルが推論できるようにする。
本アプリケーションは、LLMが「次のトークンを予測しながら文章を生成している」ことを体験的に理解できるようにすることを目的とする。

# 構成
- クライアントPC:
 - ホスト(windows): webアプリケーションを表示するブラウザ
 - WSL: webサーバを建て、推論サーバと通信する
- 推論サーバ: モデルを動かす

## アーキテクチャ

ブラウザ
    │
localhost(Webアプリ) ホストPC
    │HTTP
Python(Webサーバ) WSL
    │
SSHトンネル
    │HTTP
推論サーバ(API) 推論サーバ
    │
LLM

## 通信方法
- ブラウザはlocalhostのみ利用(外部には公開しない)
- 通信はHTTP(JSON)
- 推論サーバ・クライアントPC間のHTTP通信はSSHトンネル経由

## 起動方法
1. 推論サーバを立ち上げる(モデルをロード)
2. webアプリケーションを立ち上げる
3. ブラウザで接続

# 推論サーバAPI仕様
statelessにするため、サーバは候補だけを返し、次にどのトークンを追加するかは決定しない

## post /generate
### request
{
 "text": string,
 "top_k": number,
}
text: モデルに入力する文字列
top_k: 何番目のトークンまでをレスポンスで返すか

### response
{
 "tokens": [
  {"token_id": number, "token": string}
 ]
 "table": [
  {"token_id": number, "rank": number, "token": string, "probability": float}
 ]
}

tokens: 入力した文字列をトークンごとに区切ったもの
table: 順位、トークン、確率のテーブル

# 機能要件
## 推論サーバ
- 起動時にモデルをロード
- GPUのCUDAを使用
- 推論サーバAPIに則てテキストから次のトークンの確率を出力

## webアプリケーションバックエンド
- 推論サーバAPIを通してモデルの出力を取得

## webアプリケーションフロントエンド
フロントエンドではトークン分割を行わず、毎回全文字列を推論サーバへ送信し、推論サーバ側でTokenizerを実行する。
- モデルに入力した文字列を表示
- モデルが出力したテーブルを表示
 - 順位、トークン、文字列
- 指定されたトークン追加方式に従って、前回の文字列に新しいトークン(or文字列)を追加
 - Greedy: 1番上のトークンを追加
  - Weight: topK内の各トークンの確率を重みとしてランダムにトークンを追加
 - Random: 順位n番目からm番目までの範囲から等確率に一つのトークンを追加 (nとmをユーザーが選択)
 - Select: ユーザーが選択したテーブル内のトークンを追加 (ユーザーがテーブルから指定)
 - Input:  ユーザーが与えた文字列を追加 (ユーザーが直接入力)
- 追加したトークン(or文字列)の表示
- 推論に使用した文字列と推論結果のテーブルを履歴として保存
  以下の事項を1ステップとして保存
 - モデルに入力したトークン列(文字列)
 - モデルが出力したテーブル
 - 追加したトークン(or文字列)
 履歴に保存された任意のステップに巻き戻せる
 履歴はツリー構造にはしない。巻き戻し後に推論した場合、そのステップ以降の履歴は削除する。

# 処理フロー
1. ユーザが文字列をInputを用いて入力
2. その文字列を推論サーバに渡す
3. 推論サーバが文字列をtokenizerに入れる
4. トークン列をモデルに入力
5. 出力結果からtopKの確率テーブルをクライアントPCに送信
6. 確率テーブルを表示
7. ユーザがトークン追加方式を選んで追加するトークン(or文字列)を選択
8. 「次のトークンの予測開始」ボタンをクリック
9. 2に戻る

# 画面構成
- モデルに入力した文字列(前回追加したトークン(or文字列)の色を変える、トークンごとにスペースで分割)
- モデルが出力したTopKのトークンのテーブル (スクロールできる)
 - 順位
 - トークン
 - 確率(%表示)
- トークン追加方法の選択ボタン
 - Greedy: 押すだけで「追加する文字列」欄に自動的に1番上のトークンが表示される
 - Weight: 押すだけで「追加する文字列」欄に自動的に確率で選ばれたトークンが表示される
 -Random: startとendを選択して実行ボタンを押すと、「追加する文字列」欄に自動的に選ばれたトークンが表示される
 -Select: テーブル内の任意のトークンを選択すると、「追加する文字列」欄に自動的に選ばれたトークンが表示される
 -Input: 「追加する文字列」欄に手動で文字列を入力
- 追加するトークン(or文字列)の表示(モデルに入力した文字列の次に表示する、モデルに入力した文字列および前回追加したトークン(or文字列)とは色を変える)
- 「次のトークンの予測開始」ボタン
- 前ステップに戻るボタン
- 次ステップに進むボタン

例:

# 制約
- モデルへの最大入力長は1024トークンまで
- topKは1から256まで

# 非機能要件
- 推論サーバは起動時に一度だけモデルをロードする
- 推論サーバはStatelessに動作する
- Webバックエンドは推論サーバのプロキシとしてStatelessで動作する
- API通信はJSONを用いる
- クライアント・推論サーバ間はSSHトンネル経由で通信する
- 履歴はクライアント側のみで保持する
- ブラウザはlocalhostのみで利用し、外部公開しない
